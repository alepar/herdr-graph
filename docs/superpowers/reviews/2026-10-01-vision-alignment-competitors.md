## What is most worth borrowing

Useful practices to consider are **a human attention digest, event-driven delegated-work supervision, and a reusable project onboarding recipe**. The judges found existing responsibility assignments or deliberately open instance choices, so these are product options rather than confirmed design defects. They can make the already assigned practices concrete without expanding graph ownership. Next, make the already desired peer-learning and monitoring recovery examples concrete: publish a scoped lesson, have the relevant peer apply it without human relay, then resume a retired monitor against actual scheduler state without duplicating jobs.

Devin's automation and workflow features should inform external adapters, not become requirements that graph implement a scheduler. Firstmate supplies the clearest operational baseline to trial. Wheelhouse contributes useful instance practices and cautionary experience, but its private implementation and reported output do not establish a capability benchmark.
