to: The observer becomes a level-triggered structural differ. (1) Events, the 60s tick and reconnects only *trigger* a fresh complete `session.snapshot`; no event maps to a mutation directly. The last complete snapshot is persisted in `.graph-local/` with a connection incarnation (subscribe generation + Herdr server pid/start time where obtainable); a diff runs only between two complete snapshots of the same incarnation. (2) The first snapshot after daemon start, reconnect or incarnation change is a rebind pass: identity matching only; unmatched bound objects → `unknown`; the reconciler emits no create effects for `unknown` objects until rebind or an explicit plan. (3) Identity = a graph-owned token stamped at creation (pane.report_metadata token, or a label nonce if tokens prove not to survive restart — spike), falling back to terminal_id; a known token under a new pane_id/tab ⇒ move, label change ⇒ rename, agent gone with pane present ⇒ occupancy end — all from the diff, so dropped events are harmless. (4) Disappearances in one diff are grouped by containment: workspace gone ⇒ workspace rule; tab gone ⇒ tab rule absorbing its panes; pane gone with tab present ⇒ clone rule; a source tab emptied by a move gets one stated rule. (5) Before emitting an observed mutation, each diff element is classified against committed desired state plus journaled effects with their predicted end-state (plans predict induced container closures — retiring the last clone predicts the tab close, and plans show it); explained elements produce only bookkeeping (binding/runtime update), no window. Seat deactivate leaves clones `active` with runtime absent — explained, neither create nor retirement. (6) Observer and reconciler share one loop step: snapshot → diff → commit observed mutations → reconcile against the new committed revision and the same snapshot; the reconciler never acts on a snapshot whose observations are uncommitted.
