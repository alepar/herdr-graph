## What the cluster changes

- `init_instance` writes `GraphRecord { node_manager_seat: None, .. }`. With the field's `#[serde(default, skip_serializing_if = "Option::is_none")]` (src/model/graph.rs at head), a fresh `graph.toml` is byte-identical in shape to pre-epic instances; no `schema_version` bump, satisfying the global constraint.
- `impl Clone for StoreError` gains the `Integrity { holder, field, target, reason }` arm, a field-for-field clone. The match has no wildcard, so the compiler enforces exhaustiveness over every variant, and the clone is lossless (unlike the pre-existing lossy `Io` arm, which is unchanged). `PartialEq` compares `Display`, which for `Integrity` renders all four fields, so equality stays meaningful.
- Test fixtures `teamspace()` and `seat()` in src/store/tests.rs add `default_manager: None` and `manager: None`; purely mechanical for the new record fields.

## Spec and baseline trace

- Spec §4.8 explicitly rejects init creating the node-manager seat ("init runs before any daemon or Herdr layout exists; seat creation belongs to plans"). Leaving `node_manager_seat` unset at init is therefore the specified behavior; B10 (first seat becomes node manager, as amended by S1) is delivered through the plan kinds' first-seat helper, which lies outside this cluster and is the plan cluster's and seam reviewer's to trace.
- B7 (pointer changes only via plans): this cluster writes no manager pointer other than the initial unset value at instance creation, which precedes any plan and carries no pointer; consistent.
- B4 (named non-transient integrity error): the `Integrity` variant itself is defined in src/ports/store.rs (other cluster); this cluster only makes it cloneable, which keeps it usable wherever `StoreError` is cloned (e.g. instruction-source error paths). The IPC mapping and exit-6 rendering are other clusters' scope.
- Serde default/skip behavior for `node_manager_seat`, `manager` and `default_manager` is covered by `manager_fields_default_and_skip` and `manager_fields_round_trip` in src/model/tests.rs (model cluster), so the init output shape is tested indirectly.
