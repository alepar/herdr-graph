- The guard tests in src/templates/tests.rs make the node manager with the test-only `SetNodeManager` mutation, not through first-seat assignment. That is reasonable in isolation, but it also means no test in this module exercises the missing template-path assignment.
- Minor preview/apply divergence: in a multi-application `TemplateEdit`, one application can resurrect a retired seat R whose explicit manager is a seat W that a later application withdraws. On apply, R is live when W retires, so `do_retire_seat` rewrites R's pointer; the preview misses that rewrite because it treats R as retired. Spec §4.6 makes retired pointers transparent, so R's effective manager comes out the same either way, and only the listed effects differ.
