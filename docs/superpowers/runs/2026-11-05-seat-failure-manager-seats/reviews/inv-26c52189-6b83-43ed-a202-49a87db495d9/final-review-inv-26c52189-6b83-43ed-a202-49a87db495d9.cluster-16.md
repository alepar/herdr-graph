## What the cluster changes

- `DesiredRuntime` gains `node_manager: Option<SeatId>`, filled in `DesiredRuntime::load` through `model::manager::live_node_manager(tree)`. That is the single helper the key-abstractions digest requires; the reconcile layer does not read `graph.toml node_manager_seat` itself.
- The field is consumed outside this cluster by `observe::classify::classify` (src/observe/classify.rs:279). There it exempts the node manager's seat, clones and teamspace from workspace, tab and pane cascades. The planner (src/reconcile/planner.rs) is unchanged and does not read the field. Reopening relies on the existing behaviour of `plan_effects` for an Active seat whose runtime is Absent.
- tests.rs: a test-only `TestNodeManager` bookkeeping mutation that writes `graph.toml` directly; `fx_with` calls `plan::managers::testing::opt_out`, so existing fixtures keep `live_node_manager == None`; and a new test, `node_manager_with_absent_runtime_gets_tab_and_panes`, covering two cases: (a) the workspace is closed and every binding is Absent, so the plan creates the workspace, then the tab, then panes; (b) only the tab is closed, so the plan creates the tab and no workspace.

## Observations

- `live_node_manager` goes through `Pointers::load`, which scans all teamspaces and all seats a second time (the same lists `DesiredRuntime::load` iterates right after) and reads graph.toml. That is an extra full scan on every observer and reconcile tick. It is correct and matches the "callers never read node_manager_seat" rule. A cheaper form would compute it from the already loaded `d.seats` plus `read_graph`, but that would duplicate model::manager's rule, so leaving it is defensible.
- `DesiredRuntime::load` now fails if graph.toml is missing or unparsable (`read_graph` returns `StoreError::Corrupt`). graph.toml is written by `init_instance` and is a core instance file, so this adds no realistic failure mode. It is noted for completeness.
- In the new test, the pane assertion `pos(SplitPane).or(pos(StampToken))` is loose: it would also pass if only a token stamp were planned. The ordering assert `ws < tab` is sound, because both are asserted Some first.
- Because the fixture sets `opt_out` for every reconcile test, only the new test exercises a live node manager. That is the intended containment, since the planner does not branch on the field.
- Edge for the seam reviewer (outside this cluster): a node manager that was first moved out of its tab (tolerated per §4.9, `moved_out = true`) and whose pane is later closed is not reopened. `plan_effects` skips CreateTab for `moved_out` seats (planner.rs:610) and nothing clears `moved_out` on closure. §4.9 promises reopening "only for closure" and leaves move-then-close unspecified, so I do not count it against B11 here.
