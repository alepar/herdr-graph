## Analysis

- What the line does: `plan::managers::testing::opt_out` (src/plan/managers/mod.rs:263) commits, through git2 and before any writer opens the root, a graph.toml whose `node_manager_seat` names a freshly minted SeatId that has no seat record. Per the helper's own contract, first-seat assignment (§4.8, B10) never fires because the field is already set. `model::manager::Pointers::live_node_manager` (src/model/manager.rs:117) returns None for a pointer to a seat that does not exist, so the dangling id is treated as "unassigned", not as an integrity error. That keeps B4's integrity classification out of these fixtures.
- Why it is needed: with the epic's first-seat rule, the first seat a transcripts fixture creates becomes the node manager, and the §4.9 `make_plan` retirement guard then refuses any later plan that retires it. To check this, I removed the line in a review-owned worktree and ran `cargo test --locked --offline --lib transcripts::`. Three tests failed in `plan_and_apply` at `create_plan(...).unwrap_or_else(panic!)` (tests.rs:324): layout_compat_legacy_delivery_and_old_action_undo, layout_compat_registration_keeps_initial_attribution_through_org_changes and summary_for_an_archived_seat_lands_in_its_archive_folder. All three retire or archive seats as part of what they test. The line therefore keeps these transcripts tests about transcripts and does not weaken any manager-seat property. It also matches the pattern the other eight `testing::opt_out` call sites use.
- Run at head: in a detached review worktree at 90e9118 (inside distrobox durak-dev, because the host has no linker), `cargo test --locked --offline --lib transcripts::` gave 67 passed, 0 failed, 0 ignored.
- Requirement baseline: the design doc has a `## Requirement baseline` (B1 to B14, S1). None of its rows is delivered by, or depends on, src/transcripts. The cluster only adapts a test fixture to B8/B10 behaviour that is implemented and judged in other clusters (plan::managers, model::manager). Whether those rows are delivered end to end is for those clusters and the seat reviewer to judge.
- Minor observations, not defects: `opt_out` hardcodes `refs/heads/main` and assumes `init_instance` creates that branch. That holds today, since all 67 tests pass, and the helper lives outside this cluster. The fixture no longer exercises transcripts behaviour when the transcribed or summarizer seat is itself the live node manager. The spec makes no transcripts-specific promise for that case, so this is a coverage gap, not a missed requirement.
