R1 Each graph clone is bound one-to-one, for life, to a herdr-threads pane seat, and that seat is authoritative for the clone's location and liveness (B1)
R2 The graph no longer re-matches clones itself: its clone matching passes, planner clone re-matching and manual clone rebind are gone, with threads delegated as at least as good (B1, B3)
R3 The graph depends on herdr-threads: with threads unreachable it changes no clone binding and fabricates no seat state (B2)
R4 After a Herdr cold restart, including a headless one, clones recover (agents resumed or relaunched, seats reattached) without an operator step (B4)
R5 After a Herdr live handoff (herdr update --handoff), clones recover without an operator step (B5)
R6 No Herdr change is required (B6)
R7 Closing a clone's pane retires its seat immediately; graph undo reopens the tab, resumes the session and un-retires the same seat (B7)
R8 An agent exiting while its pane stays open keeps the seat and its memberships (B8)
R9 Graph-launched agents carry a reserved continuity key that threads uses to reattach the clone's seat (B9)
R10 Graph undo restores the seat's memberships with no re-acceptance (B10)
R11 /seat prints no acceptance commands; acceptance follows herdr-threads' own command and procedure (B11)
R12 Thread participation is keyed to the clone's seat, so /clear or a relaunch on the same pane causes no release or re-invite (Goal)
R13 Seats (tabs) and teamspaces (workspaces) are matched across Herdr incarnations by preserved Herdr ids (spec §7)
R14 The graph runs on herdr-threads v3.0.0 or later (spec §1)
R15 The graph's herdr-threads dependency is raised to each release that ships D1, D2 and G5 as it lands (R-new r1)
R16 A clone whose pane was closed while Herdr was down gets a defined outcome: retired and undoable, never resumed into a missing pane (R-new r1, merged)
R17 Clones closed before the upgrade (no threads_seat recorded) can still be undone or resurrected (R-new r1)
R18 The operator has a documented resolution path for a key-conflict clone now that manual rebind is removed (R-new r1)
R19 The resume driver launches only after a Herdr restart; an agent exiting from a still-open pane triggers no launch (R-new r1)
R20 Before deletion, threads delegation is shown at least as good as the removed clone matcher across its scenarios (R-new r1)
R21 After D2, seat succession is limited to final-retired seats (R-new r1)
